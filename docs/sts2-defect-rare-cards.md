**关键方法（这是本次最值钱的一条经验）**：Game8 的卡页 ID **按品质成段排列**。

## 4. ⚠️ 二代机制差异（会直接影响接线，不属卡表但必须读）

来源：<https://sts2front.com/characters/defect/>

1. **集中力在二代是临时的**：一代的永久叠加没了。`Consume` 删除；`Defragment` 降为 UNCOMMON 的路线被砍、
   实为**变 RARE**；`Biased Cognition` 只存在于 Ancient 奖励。主来源是「同期 / Synchronize」（1 费技能：本回合每生成过 1 种球 +2 集中，仅本回合）。
2. **暗球 / 等离子球不吃集中力**，只有**闪电 / 冰球**吃 —— 与本 MOD 现有实现一致。
3. **二代新增第 4 种球「グラス / Glass（玻璃球）」**：被动对全体造成"划伤伤害"，激发造成更大划伤伤害，**每回合衰减**。
   **本 MOD 的 `Orb` 枚举里没有这个球种** → スピナー、以及「同期满 4 种球 +8」这类设计都依赖它。
   **要实现玻璃球＝引擎级改动**（改 `Orb` 枚举 + 被动/激发结算 + 衰减状态），
   **不是"加 3 张卡"的量级，建议单独立项**。
4. 卡数口径冲突：`sts2front` 称机宝约 **89 张**；交接稿记录 untapped 称 **95 张**。
   原因是版本/口径不同（EA 期间卡池在改，Game8 也注明"未收录 Beta 版要素"）。
   **不要在文档里断言唯一数字。**
