# 遗物全表（自动导出）

> 由 `com.slaythecraft.tools.ExportRelics` 从 `RelicLibrary` **直接导出**，所以和代码永远一致；改完遗物重跑一次即可。
>
> 复现命令（**不需要 MC 类路径**）：
>
> ```powershell
> .\gradlew.bat compileTestJava --offline
> java "-Dstdout.encoding=UTF-8" -cp "build\classes\java\main;build\classes\java\test" com.slaythecraft.tools.ExportRelics
> ```
>
> 产出两个文件：`docs/relics-export.md`（这份报告）与 `docs/relics-export.csv`（给表格软件，**带 UTF-8 BOM**，否则中文 Windows 的 Excel 会按 GBK 读成乱码）。

**商店售价（v0.5.3.1 / v0.5.3.2，用户逐件给定）**：14 件有单价，区间 195~240 金币，均价 212 金币。没有单价的只有**初始遗物**与**事件限定遗物** —— 它们根本不上架，所以「商店里能出现的每一件遗物都有明确单价」，配置统一价 `shopPriceRelic`（默认 150）只剩兜底作用。

**来源通道（v0.5.3.1）**：`战斗掉落` = 精英 / BOSS 必掉 + 常规战斗 10% 那一档；`藏宝箱` = 副手收纳包 + 主手镐右键陷阱箱；`商店` = 卡牌大师的遗物货架。

**带额外机制的遗物**：属性类加成不走触发点，由引擎的专门方法实现 —— 药水栏位 +2（【药水腰带】）、最大生命 +14（【嚒咕菲力】）、每场战斗结束最大生命 +1（【蜂蜜佐料】）、每回合少抽 1 张（【嚒咕菲力】）。

## 4. 已知偏差

* 遗物**没有任何美术资源**：战斗左侧遗物栏用程序化符文兜底，丢一张 `assets/stc/textures/relic/<id>.png` 就会变成真图标。
* 遗物表是**代码注册表**（`RelicLibrary`），不是数据包注册表 —— 整合包要自定义得等 A6 那一类改造。
* 遗物**没有稀有度字段**，所以商店/掉落是等概率随机（`randomUnowned`）。
* 商店里能出现的遗物（14 件）**每一件都有明确单价**；只有初始遗物与事件限定遗物没有价，而它们根本不上架。
* 【袭击号角】【失活的珊瑚】【海洋之心】是**旗标型**：效果只负责在自己身上点亮一个旗标，真正的数值修正在 `previewDamage` 等结算处读取；另外 `applyPassiveBonuses` 里还有一份「开战前直接按 id 点亮」的等价入口（离线自检用）。
