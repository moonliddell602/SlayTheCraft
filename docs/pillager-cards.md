## 新增卡牌的代码模板

按项目约定：**类级字段** + **独立的 `static { }` 写强化版**（不要塞进那个大静态块里），
效果体抽成私有静态方法。`register(...)` 进基础池，`upgrade(...)` 进强化池。

```java
// 基础版：叛逃掠夺者专属，普通品质，1 费攻击
public static final Card MY_CARD = register(new Card(
        "my_card", "我的卡", CardType.ATTACK, 1, CardTarget.ENEMY, "造成 8 点伤害。",
        CardRarity.COMMON, PILLAGER,
        (ctx, self, target) -> ctx.dealDamage(self, target, 8, "「我的卡」")));

// 强化版：同一个 id、名字带「+」、数值更高 —— 必须与基础版**同批**写上
static {
    upgrade(new Card("my_card", "我的卡+", CardType.ATTACK, 1, CardTarget.ENEMY,
            "造成 11 点伤害。", CardRarity.COMMON, PILLAGER,
            (ctx, self, target) -> ctx.dealDamage(self, target, 11, "「我的卡」")));
}
```

**加卡时的两条纪律**（项目里踩过坑）：

1. **先查 id 是否被占用**：id 撞车会**悄悄覆盖别人的强化版**；
2. **每张非状态/非诅咒牌都必须有强化版** —— 自检会以「每张非状态/非诅咒牌都有强化版」拦下来。

## 写新卡时可用的引擎原语

| 原语 | 用途 |
| --- | --- |
| `ctx.dealDamage(self, target, n, label)` | 造成伤害（返回未被格挡的实际掉血，可用于「回复未格挡伤害」类卡） |
| `ctx.grantPlayerBlock(n, label)` | 获得格挡（会走迅捷/缓慢修正） |
| `ctx.grantEscortBlock(self, n, label)` | **全场存活玩家**各加 n 点格挡，并挂上【商队护送】的结算（v0.5.3.1） |
| `ctx.drawCards(self, n)` / `ctx.gainEnergy(self, n)` | 抽牌 / 获得能量 |
| `ctx.addToDrawPile(self, card, n)` | 往**抽牌堆**加牌（`insertCards` 只进弃牌堆） |
| `ctx.putOnTopOfDrawPile(self, card)` | 把一张牌放到抽牌堆**顶** |
| `ctx.discardPile(self)` / `hand(self)` | 读弃牌堆 / 手牌 |
| `ctx.moveDiscardToDrawPileTop(self, index)` | 弃牌堆选一张置顶（自动选版本） |
| `ctx.transformInHand(self, index, replacement)` | 手牌变形成另一张 |
| `ctx.exhaustFromHand(self, indices)` | 手牌消耗 |
| `ctx.lastX(self)` | 取 X 费卡的 X（配合 `registerXCost`） |
| `ctx.stunEnemy(enemy)` | 击晕（当前回合意图改成「晕眩」，不扣血） |
| `ctx.dealRandomDamage(self, times, n, label)` | 对随机敌人打 N 次（**每次独立随机选目标**） |
| `ctx.announce(text)` | 战报里写一行（不静默） |
| `self.addStrength/addDexterity/addFocus/...` | 给自己加状态 |
| `target.addVulnerable/addWeak/addBurn/addPoison/addDecay/...` | 给目标加状态 |
| `ctx.channelOrb(self, Orb.XXX)` | 生成充能球（只有故障机器人有球位） |
