### 25 测试反馈修正验收（v0.2.1）

这一节对应 7 条实机反馈，逐条给出验收方法：

1. **精英 / BOSS 战只卷 1 只**：站在**离你最近的**是精英（如远古守卫者 / 劫掠兽 / 铁傀儡）处开战 →
   只有那一只精英进战斗，旁边的小怪不会跟进来；BOSS 战同理（监守者 / 凋零 / 末影龙只来 1 只）。
   唯一的例外是**猪灵蛮兵小队**：仍然是 2 只（`eliteSquad=false` 可关掉）。
2. **周围只加 3 个敌人**：在 5 只僵尸中间开战 → 只会进来最近的 **3** 只（`maxEnemies` 可调）。
3. **不能中途换角色 + 重开按钮**：
   - 本局没打完时在尖塔入口点别的角色 → 被拒绝并提示"本局还在进行（第 N 层）：不能换角色"；
   - 打赢三层 BOSS（或用 `/stc progress endrun` 模拟战败）后再点角色 → 开**新的一局**，
     牌组只发一份起始牌、不再叠加；
   - 点「重开本局」→ 面板里再点一次确认 → 卡牌/遗物/药水/进度清空、生命回满、**金币保留**。
4. **卡牌页不重叠**：按 B → 拥有卡牌 → 用**滚轮**上下滚动（右侧有滚动条）；
   下方是**独立的详情面板**（摘要 + 描述 + 删除按钮），"显示 x–y / 共 N 张"在面板右侧，不再压着卡牌。
5. **药水栏只在战斗内**：战斗外整排药水槽位不再显示；进战斗后出现在手牌上方（按 ESC 收起出牌界面时仍在）。
6. **俯瞰 45°**：进战斗 → 自动第三人称 + 镜头俯视 45°（`battleCameraPitch`，设 0 可关掉）；
   左右仍可自由转视角。
7. **怪排到正前方**：开战瞬间怪物被拉到你的正前方一字排开（≥5 格、面朝你），聊天栏会提示
   "站位：N/N 只敌人被排到你正前方 5 格处"；怪物脚下没有安全落点时它保持原位（不会被塞进墙里）。

### 27 效果与状态可见性验收（v0.2.3 / W1）

1. **虚弱新语义**：`/stc status add weak 2` → 打「打击」→ 伤害 **4**（6×0.75），
   敌人头顶的意图伤害预览也同步变小；虚弱每回合自动 −1，减伤比例**不随层数变多而叠加**。
2. **易伤新语义**：给敌人 `/stc status add vulnerable 2` → 打「打击」→ 伤害 **7**（6×1.25）。
   两者同时存在时先算虚弱再算易伤（`floor(floor(6×0.75)×1.25)=5`）。
3. **活力**：`/stc status add vigor 4` → 下一张攻击牌多打 4 点（打击 6+4=10），打完活力清零；
   中间打技能牌不会消耗活力。
4. **失去生命值**：先攒格挡（打「格挡」）×2，再让灼烧/凋零跳一次 → **格挡不减、直接掉血**；
   敌人普通攻击则照旧先扣格挡。
5. **卡面数值实时化**：给自己上虚弱 2 → 手牌里【打击】描述变成"造成 4 点伤害"，
   【格挡】在自己有迅捷/缓慢时显示 7 / 3 点格挡。
6. **敌人效果**：给敌人上虚弱 5 与易伤 2 → 敌人框（意图下方）显示"虚弱 5 · 易伤 2"。
7. **自己的效果**：自己有多种状态时，药水栏**左侧**逐条列出（超过一行自动换行，最多 4 行）。
8. **退出战斗**：按 ESC → 界面暂时收起并在 4 秒内自动弹回（战斗不会卡住）；
   点右上角「放弃战斗」→ 变成「确认放弃？」→ 再点一次真的离开，敌人立刻解除冻结并恢复 AI。

### 28 状态牌验收（v0.2.5 / W2）

```
/stc status card <id> [数量]   往自己的弃牌堆塞状态牌（id: void/slimed/burn/dazed/venom/call）
```

1. `/stc status card burn 2` → 过几个回合把这些牌抽上手（灰色「无法打出」）→ 回合结束时每张
   对你造成 **4 点伤害**（有格挡会先扣格挡）。
2. `/stc status card void 1` → 抽到它的瞬间本回合**费用 −1**（能量数字立刻变小）。
3. `/stc status card call 1` → 回合结束时**失去 5 点生命值**（格挡不减）。
4. `/stc status card slimed 1` → 这张是**能打的**：1 费抽一张牌并消耗。
5. `/stc status card dazed 1` → 不能打出，回合结束被**虚无**消耗（进消耗堆）。
6. 打骷髅 / 史莱姆 / 洞穴蜘蛛 / 岩浆怪 / 女巫时，意图栏会出现「塞入状态牌（将把 N 张「X」放进…）」，
   执行后这些牌真的会进你的弃牌堆。

### 29 测试反馈修正验收（v0.2.2）

1. **奖励一定能触发**：打一场普通战斗（创造模式也一样）→ 胜利后**立刻弹出三选一** + 金币
   （普通 16 / 精英 40 / BOSS 60，BOSS 必出金色）；聊天栏会写「战斗胜利奖励（普通档）：+16 金币…」。
   原因说明：以前战斗击杀走的是引擎处决（无来源伤害），原版击杀归属为空 → 从来没记过账；
   现在由引擎按"最后一击的玩家"直接记账。
2. **击杀进度可见**：每杀一只怪，聊天栏出现「击杀进度：zombie 3/5（普通档）」；
   同种类累计达标（普通 5 / 精英 3 / BOSS 1）再额外给一次奖励。
3. **待领期间不会被攻击**：拿到奖励后先不选，站着让僵尸打你 → 不掉血；按 ESC 关掉界面后
   大约 3 秒会**自动再弹**；没领完之前点「开始对战」会被拒绝（提示先领完奖励）。
4. **收纳包不再领奖**：按 B 打开收纳包 → 主页只剩三个模块（拥有卡牌 / 拥有遗物 / 事件回合统计）
   加一行奖励状态说明；`/stc reward open` 仍然可以手动打开（管理员调试用）。
5. **独立生命值彻底独立**：原版血条（红心）与独立生命值互不影响 —— 受原版伤害不会掉独立生命值，
   独立生命值归零**不会**让原版角色死亡/掉物品；数字只在战斗界面与收纳包「事件回合统计」里显示。

### 30 收纳包触发与页面约定验收（v0.2.6）

1. **手持即算携带**：把【卡牌收纳包】拿在**主手**（或副手）→ 按 B 能打开界面、尖塔入口能「开始对战」。
2. **背包里也能开界面（v0.4.6.5 起）**：把它放回背包（手上换成别的）→ 按 B / 右键它 / 尖塔入口的
   「查看卡组」都能打开收纳包界面；但此时「开始对战」仍会被拒绝（提示"需要携带【卡牌收纳包】才能开始尖塔对战"），
   把它拿回**主手或副手**即可参战。
3. **Curios 可选**：装了 Curios 且装备在饰品槽里时，同样算携带（不再要求必须占用饰品槽）。
4. **子页面都是独立页面**：按 B → 主页只有三个模块 → 点「拥有卡牌 / 拥有遗物 / 事件回合统计」
   各自打开**独立的新页面**（不是在同一页里切视图），每个页面底部有「返回」回到主页；
   卡牌页滚轮滚动、下方独立详情面板、删除仍在确认框里再点一次。
5. **重开是独立页面**：尖塔入口点「重开本局」→ 进入独立的确认页面（确认重开 / 取消），
   两个按钮都回到入口页；不会再出现盖在原页面上的确认框。

### 31 页面化与文本完整性验收（v0.2.7）

1. **卡牌详情是新页面**：按 B →「拥有卡牌」→ 点任意一张卡 → 进入**独立详情页**
   （名称 / 费用·类型·品质 / 关键字 / 附魔 / **完整描述按宽度折行**，长描述不会缺字）→「返回」回列表。
2. **收纳包不能删卡**：详情页里**没有**删除按钮；列表页提示也不再写删除。
3. **回收站能删卡**：空手右键【卡牌回收站】→ 点卡 → 详情页出现「删除卡牌（100 金币）」→
   进入**独立确认页**（确认删除 / 取消）→ 确认后扣金币、卡牌消失。
4. **商人也能删卡**：右键【卡牌商人】→ 商店页底部「删卡服务（100 金币）」→ 同样的选卡 → 详情 → 确认流程。
5. **遗物描述完整**：按 B →「拥有遗物」→ 点一件遗物 → **独立详情页**看完整描述（列表里不再截断半句）。
6. **重开确认也是独立页**：尖塔入口「重开本局」→ 独立确认页（确认重开 / 取消 / ESC 取消）。

### 32 受惊的小猪仔效果验收（v0.2.8）

1. Shift + 右键小猪仔 → 「安抚它」拿到遗物【受惊的小猪仔】；按 B →「拥有遗物」→ 点它，
   详情页应显示两行："每场战斗第一次失去生命值时，抽 3 张牌。" + "至少你救下了一条生命，不是吗？"
2. 进战斗让敌人打你一下（**真的掉血**）→ 战斗日志出现【受惊的小猪仔】并**抽 3 张牌**。
3. 同一场战斗里**第二次**掉血 → **不再抽牌**（每场战斗只有第一次生效）。
4. 全程用格挡把伤害挡住（没掉血）→ **不触发**。
5. 多人：让队友先掉血 → 抽牌抽到他手里，不会抽到当前行动玩家手里。

### 33 角色系统验收（v0.2.9 / W3）

1. **四个角色都在**：尖塔入口页从上到下是 铁甲战士 / 静默猎手 / 故障机器人 / 叛逃掠夺者，
   四张卡片都能完整显示（不重叠、不超出面板）。
2. **点角色卡新开详情页**：卡片上写着「点击查看详情」，点任意一张 → 进入**独立详情页**：
   程序化头像、**角色描述（按宽度折行）**、初始牌组（按种类合并成「打击 ×4」）、
   **初始遗物名字 + 完整描述**；底部「选择这个角色」/「返回」。
   叛逃掠夺者的头像是"左眼闭合 + 一道伤痕"的掠夺者。
3. **选择在详情页里完成**：点「选择这个角色」→ 回到入口页，该角色变成金色高亮并显示「当前角色」。
4. **初始遗物按原版**：铁甲战士=燃烧之血（战斗胜利回 6 血）、静默猎手=蛇之戒指（开局多抽 2 张）、
   故障机器人=破损核心（开局生成 1 颗闪电球）、叛逃掠夺者=臂弩（开局把【箭在弦上】放进手牌）。
   新开一局（或点「重开本局」）后，遗物栏里应当**正好**只有这件初始遗物。
5. **叛逃掠夺者的牌**：起始牌组 12 张 = 打击×4 + 防御×4 + 专注射击 / 寻找掩体 / 翻滚 / 烟雾弹；
   翻滚带「消耗」（翻滚+ 去掉消耗）、烟雾弹+ 费用变 0；【箭在弦上】是 0 费状态牌（获得活力 4），
   任何奖励/商店都刷不到它，只有【臂弩】会发。
6. **寻找掩体是两段格挡**：打出后当回合 +9 格挡，**下个回合开始**格挡被清空后又补上 5 点。

### 34 充能球验收（v0.2.9 / W4）

1. **球显示成方块、绕腰一圈**：选故障机器人开战，用【电击】生成闪电球 →
   玩家腰部高度出现一个缓慢环绕的方块（黄色蛙鸣灯）；用【冰球】→ 蓝冰。
   **空栏位显示为标靶**（3 格全空时能看到 3 个标靶）。
2. **被动在回合结束时触发**：回合结束时闪电球对**随机敌人**造成 3 点伤害（战斗日志有记录）；
   冰球给 2 点格挡，且**先给格挡再轮到敌人行动**（敌人打 5 点时只掉 3 血）。
3. **栏位满了先激发最前面那颗**：3 格满了再生成第 4 颗 → 最前面那颗被激发（闪电球 = 8 点伤害、
   冰球 = 5 点格挡），新球排在最后。
4. **双重释放**：手上有 2 颗闪电球时打出【双重释放】→ 激发 2 次共 16 点伤害（双重释放+ 激发 3 次）。

### 52 素材工作区（`assets/`）与打包流程

需求（v0.4.6.5）："在当前项目内的合适位置留下可用于我开发的 assets 文件夹，
以方便我直接导入素材以及你后续的打包。"

所以项目里现在有两个 `assets`，分工明确：

| 目录 | 作用 | 是否进 jar |
| --- | --- | --- |
| **`assets/`**（项目根目录） | **素材工作区**：你放卡牌插画 / 贴图 / 模型 / 音乐 / 音效 / 字体 / 翻译，放 PSD、`.bbmodel` 大文件也无所谓 | ❌ 不进 |
| `src/main/resources/assets/stc/` | **打包目录**：真正的模组资源，只有进到这里才会被打进 jar | ✅ 进 |

#### 工作区结构（每层都有 README 说明命名规则与落点）

```
assets/
├── README.md                 ← 总说明（先看这个）
├── 素材清单.md               ← 可选的清单模板：告诉我每个文件是什么、用在哪
├── cards/                    → src/main/resources/assets/stc/textures/card/
├── textures/items/           → .../textures/item/
├── textures/blocks/          → .../textures/block/
├── textures/gui/             → .../textures/gui/
├── textures/status/          → .../textures/status/
├── textures/entity/villager/profession/   → .../textures/entity/villager/profession/
├── models/item/              → .../models/item/
├── models/block/             → .../models/block/
├── sounds/boss/floor_1|2|3/  → .../sounds/boss/floor_<层>/
├── sounds/sfx/               → .../sounds/sfx/
├── fonts/                    → .../font/
└── lang/                     → 合并进 .../lang/zh_cn.json、en_us.json（不自动复制）
```

#### 同步与打包

```powershell
# 预览会复制什么（dry-run，不动文件）
.\tools\import-assets.ps1
# 真的复制进打包目录
.\tools\import-assets.ps1 -Apply
# 然后出 jar
.\gradlew.bat build        # → build\libs\stc-<版本>.jar（我还会复制一份到 dist\）
```

脚本只认素材文件（`.png .jpg .jpeg .ogg .wav .ttf .otf .json`），跳过 README；
`assets/lang/**` **不会**自动覆盖现有语言文件（那两份 JSON 里已经有两百多个键，自动覆盖会丢），
需要我按语言合并。
