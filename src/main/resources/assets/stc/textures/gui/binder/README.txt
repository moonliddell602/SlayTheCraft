收纳包界面皮肤（可自定义，v0.4.6.5）
=====================================

这个目录里放**卡牌收纳包系列界面**的可选贴图。放一张就换一处，全都不放就用模组自带的
程序化画法（羊皮纸 + 棕色按钮 + 小脸头像）。所有文件都是**可选**的，可以只放其中一部分。

三个槽位
--------

1) 书页背景  background.png
   会把**整张图拉伸**到面板矩形上（默认面板 268×300，窗口小的时候会等比收缩）。
   建议就按 268×300 画；放进这张图之后，程序化的羊皮纸底色、书脊、页边都不会再画，
   整块背景交给你。页眉文字、页脚按钮仍然画在它上面。

2) 按钮  button.png / button_hover.png / button_disabled.png
   按**九宫格**绘制：四个角保持原尺寸，四条边与中心拉伸，所以按钮宽度不一样也不会变形。
   贴图尺寸随意（绘制时会读原图尺寸），但**四个角各留 3 像素**不缩放：

        ┌───┬─────────┬───┐     3 像素边框（角固定）
        │ 1 │    2    │ 3 │     2/8 = 上下边（横向拉伸）
        ├───┼─────────┼───┤     4/6 = 左右边（纵向拉伸）
        │ 4 │    5    │ 6 │     5     = 中心（双向拉伸）
        ├───┼─────────┼───┤
        │ 7 │    8    │ 9 │
        └───┴─────────┴───┘

   常用按钮尺寸：52×14（返回 / 小型）、96×14、118×14、140×14（商店底部）。
   悬停态缺文件时会用正常态；禁用态缺文件时也用正常态。

3) 人物头像  avatar_<角色>.png（如 avatar_ironclad.png）、通用 avatar.png
   等比压进页眉那个 22×22 的方框。查找顺序：
   角色专属（avatar_ironclad / avatar_silent / avatar_defect / avatar_pillager）→ 通用 avatar.png
   → 都没有才画程序化小脸（底色按角色区分）。

换资源包 / 换图后最多 5 秒生效（贴图存在性有 5 秒缓存），不用重启游戏。

用代码指定（整合包 / 附加模组）
-------------------------------

不想用约定路径时，可以用接口指定（优先级高于上面这些文件）：

    StcApi.registerBinderBackground(id("mypack:gui/my_book"));           // 传 null 恢复默认
    StcApi.registerBinderButtons(id("mypack:gui/btn"),                  // 正常
                                 id("mypack:gui/btn_hover"),              // 悬停
                                 id("mypack:gui/btn_off"));               // 禁用
    StcApi.registerBinderAvatar(id("stc:ironclad"), id("mypack:gui/me")); // 角色专属，传 null 撤销
    StcApi.registerBinderDefaultAvatar(id("mypack:gui/default_face"));    // 通用兜底

哪些界面会用到
--------------

收纳包主页 / 拥有卡牌 / 拥有遗物 / 事件回合统计 / 查看图鉴（遗物、卡牌、无色牌、状态与诅咒牌、
敌人阵营、阵营详情、怪物详情）/ 卡牌详情 / 选择页面 / 二次确认页 / 篝火（锻造、包扎）——
它们共用同一套画法，所以改一次全局生效。
